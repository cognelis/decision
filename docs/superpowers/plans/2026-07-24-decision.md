# Decision Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and install a macOS Electron app that receives explicit development decisions from Claude Code and Codex, returns the user's choice, asks for rationale, and stores recorded decisions as Obsidian Markdown with a rebuildable SQLite index.

**Architecture:** A TypeScript monorepo contains a local stdio MCP bridge, an Electron app, and focused protocol/core/storage/integration packages. The bridge forwards authenticated loopback requests to the running app; only the app owns the decision queue and persistence. Markdown is the source of truth, while `node:sqlite` provides a disposable FTS index.

**Tech Stack:** Electron 43.2.0, React 19, TypeScript 7, Vite, Electron Forge, MCP TypeScript SDK, Zod, Node `node:sqlite`, YAML, Vitest, Testing Library, Playwright Core

```ts
export class MarkdownRepository {
  async write(record: DecisionRecord): Promise<StoredNote> {
    const target = this.pathFor(record);
    const temporary = `${target}.${process.pid}.${randomUUID()}.tmp`;
    await mkdir(dirname(target), { recursive: true });
    await writeFile(temporary, serializeDecision(record), { encoding: "utf8", mode: 0o600 });
    await rename(temporary, target);
    return { id: record.id, path: target, contentHash: hash(content) };
  }
}
```
