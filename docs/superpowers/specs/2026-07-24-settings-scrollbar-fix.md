# 设置页虚假滚动条修复设计

## 问题

设置窗口固定为 680×430。状态栏和卡片区域布局后，`.settings-grid`
的可见高度是 309px，三张卡片与网格间距共占 303px。现有 14px
底部内边距使总滚动高度达到 317px，产生了 8px 的虚假溢出，因此
macOS 显示一个几乎占满轨道的滚动条。

## 方案

将设置网格的底部内边距从 14px 调整为 6px。左右内边距、窗口尺寸、
卡片尺寸和网格间距保持不变；`overflow: auto` 继续保留，因此有待补
理由等真实内容超出窗口时仍可正常滚动。

不采用增高窗口，因为当前尺寸需要适配较小屏幕；不采用隐藏滚动条，
因为这会让真实溢出内容失去滚动位置提示。

## 验证

增加 680×430 设置页布局回归检查，断言默认空待办状态下
`.settings-grid.scrollHeight <= .settings-grid.clientHeight`。同时验证待办
内容增多时容器仍保持 `overflow: auto`，并运行完整测试、类型检查、
打包和应用启动检查。
