# 设置页极简标题栏设计

## 问题

设置窗口左上角同时出现关闭按钮、Logo、产品名、分隔符和“设置”，在仅
680px 宽的紧凑窗口中形成四个相邻视觉重心。品牌信息没有帮助用户完成
设置任务，也让标题栏更像启动页而不是轻量工具面板。

## 方案比较

1. **仅保留关闭按钮的紧凑拖动栏（采用）**：职责清晰，不与内容重叠，
   同时保留足够的窗口拖动区域。
2. 完全移除标题栏并悬浮关闭按钮：更极简，但会减少拖动区域，并可能与
   下方状态卡片碰撞。
3. 只保留“设置”标题：仍然增加一个不必要的视觉重心，改善有限。

## 视觉与交互

- 删除设置标题栏内的 Logo、`Decision`、分隔符和“设置”；
- 保留左侧 28px 关闭按钮、现有点击行为和 `no-drag` 区域；
- 标题栏由 52px 缩短为 44px，左右内边距保持 15px；
- 标题栏空白区域继续作为拖动区域；
- 保留现有磨砂、分隔线、圆角、主题和回答界面样式；
- 下方状态卡片随标题栏缩短自然上移，不改变卡片结构。

## 验证

扩展真实 Electron 布局探针，断言设置标题栏不再渲染品牌区域、高度为
44px、关闭按钮仍靠左，并继续通过既有磨砂透明和无虚假滚动条测试。
随后运行完整测试、类型检查、打包、签名、安装和真实应用视觉检查。
