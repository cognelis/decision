# 设置页磨砂与标题栏调整设计

## 问题

macOS 窗口仍启用了透明背景、`under-window` vibrancy 和 CSS
`backdrop-filter`，但深色主题的窗口底色不透明度为 76%，卡片为 62%。
两层叠加后卡片区域实际约 91% 不透明，系统磨砂几乎不可见。浅色主题
的相同叠加约为 68%，也弱于此前确认的激进透明效果。

关闭按钮当前是标题栏最后一个元素，由 `space-between` 推到最右侧，
不符合新的左侧位置要求。

## 视觉方案

保留原生 vibrancy 和现有模糊强度，只降低 CSS 颜色层的 alpha：

- 浅色主题：窗口 38%、工具栏 14%、卡片 24%；
- 深色主题：窗口 54%、工具栏 22%、卡片 38%；
- 同步降低 raised、hover 和 inset 表面的 alpha，维持层级差异；
- 文本、边框、阴影、强调色和窗口尺寸保持不变。

设置标题栏改为左对齐流：关闭按钮是第一个元素，品牌区紧随其后，
两者间距 10px。关闭按钮继续使用 `no-drag`，标题栏其余区域继续支持
拖动。

## 验证

真实 Electron 预览分别读取深浅主题的 CSS token，断言窗口、工具栏和
卡片 alpha 不超过设计预算，同时保留 `backdrop-filter`。渲染测试断言
“隐藏设置”按钮是标题栏第一个子元素。最后运行完整测试、类型检查、
打包、签名和安装包冒烟测试。
