# 产品迭代记录：2026-09-24

目标：完善核心记录、结果回填、复盘与原则沉淀流程。约 2 小时为投入上限；不提交、推送、发布，不覆盖已有未提交工作。

## 优先级

1. 复盘到原则提炼直接携带来源：现有按钮仅打开首页，用户必须重新找入口与证据；价值高，复用现有选择器，风险低。
2. 首页结果回填后连续完成复盘：目前每一步都关闭弹窗，再次寻找同条记录；价值高，复用已有保存 API，风险低。
3. 主动记录时直接安排复盘日期：保存接口已有字段，表单未提供；避免保存后再寻找详情补计划。
4. 后续依据真实操作继续发现，不为耗满时间增加能力。

## 第 1 轮：复盘 → 原则提炼（完成）

- 场景：用户完成一条决策复盘，希望立即用它整理原则。
- 交付：详情“用于提炼原则”直接打开证据选择器并预选本条；超过常规 200 条列表的来源按 ID 补查；失效来源给出提示且不选中，不自动调用模型。

- 实测发现预览原有跨页 API 是空操作，补上内存快照订阅通知，使该流程可实际验证，不访问真实 Vault。
